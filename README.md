# Active Subspace Uncertainty Quantification for Coarse-Grained Molecular Dynamics

This is a repository to reproduce the results of:

Maxime Vassaux, Xinju Dong, Shunzhou Wan, Wouter Edeling, Yiming Yang, Antigoni Georgiadou, Peter Coveney, *Reliabilty of coarse-grained molecular dynamics simulation of biomolecules using large-scale aleatoric and parametric uncertainty quantification*, 2026 (submitted).

## Contents

* `data/`: folder which contains the CG MD data generated on OLCF Frontier.
* `das_pytorch.ipynb`: jupyter notebook with pytorch code for reproducing the deep active subspace results.
* `kas.ipynb`: Jupyter notebook for reproducing the kernel active subspace results using Gaussian process surrogates.
